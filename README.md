# Automatic Car Rain Wiper System

## Overview
This project is an IoT-based automatic rain detection system for vehicles. It detects rain and automatically activates a wiper mechanism using sensor input and Arduino control.

## Problem Statement
Manual control of car wipers can be inconvenient during sudden rain. A system that automatically detects rain and activates wipers improves safety and convenience.

## Solution
This system uses a rain sensor to detect moisture and automatically triggers a motor mechanism to simulate wiper movement.

## Features
- Automatic rain detection
- Motor-based wiper simulation
- Real-time response using Arduino
- Simple embedded control logic

## Components Used
- Arduino UNO
- Rain sensor
- Motor / servo motor
- Basic electronic components

## Working Principle
The rain sensor detects moisture on its surface. When rain is detected:
- Sensor sends signal to Arduino
- Arduino processes input
- Motor is activated to simulate wiper motion
